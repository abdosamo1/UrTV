# Photo credits

The backgrounds were chosen by the owner of this repository and are not credited on screen. They are the same five
files in both places:

- `assets/backgrounds/`: bundled with the apps (offline, and the home screen's wallpaper)
- `photos/`: the hosted set the screensaver and the home screen rotate through (`photos/index.json`)

| File | Picture |
|---|---|
| `islamic-green.jpg` | gold mandala on dark green |
| `calligraphy.jpg` | Arabic calligraphy on a dark gradient (its author's signature is in the picture) |
| `lantern-cream.jpg` | hanging lanterns and gold ornaments on cream (dimmed on screen, so the white text reads) |
| `lanterns-gold.jpg` | glowing lanterns under gold mandalas |
| `lantern-teal.jpg` | a lantern on wood, teal lights behind |

Each was upscaled to 1920×1080 from the size it came in.
